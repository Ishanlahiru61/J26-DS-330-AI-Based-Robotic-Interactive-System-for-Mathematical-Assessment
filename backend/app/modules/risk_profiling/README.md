# Learning-Risk Profiling — Member 4

This module combines mathematical performance, recommendations, behaviour, and
history to estimate topic mastery and persistent patterns. It produces
explainable low/moderate/high educational screening indicators and next actions.
It does not diagnose dyscalculia or any medical condition.

Layering: `api.py -> service.py -> domain/ -> integration, feature, mastery, risk,
explainability, and model adapters`.
